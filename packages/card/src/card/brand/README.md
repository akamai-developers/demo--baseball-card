# Akamai logo

`akamai-logo-white.svg` is the all-white mark from the 2025 logo pack at
https://www.akamai.com/newsroom/media-resources, for navy surfaces. It is the
pack's artwork with the viewBox cropped from the 1920x1080 canvas to the mark.
Nothing else changed.

The `akamai` style draws it on the name plate of the front. The `classic`
style has no logo.

Rules from the brand guide: the wordmark never appears without the wave,
proportions stay as provided, no recoloring, no effects, no redrawing.

The logo is Akamai's trademark. The Apache-2.0 licence of this repo does not
cover it.
